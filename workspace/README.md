# Directorio de trabajo (sandbox del servidor MCP)

Este directorio es el **único** directorio al que el servidor MCP de sistema de archivos
tiene acceso (configurado como argumento del servidor en `config/`). El modelo no puede
leer, escribir ni listar nada fuera de esta carpeta.

Los archivos que aparezcan aquí durante la Parte 2 (creados, leídos o modificados a
través de las herramientas del servidor MCP) se dejan como evidencia de las operaciones
realizadas.
